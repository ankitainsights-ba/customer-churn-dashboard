# Customer Churn Analytics Dashboard

An interactive Excel dashboard analysing why customers churn
and what it costs the business.

![Dashboard](images/dashboard.png)

## Key Findings
1. Payment delay is the strongest churn signal.
2. Monthly contracts are the biggest retention risk.
3. Plan type isn't the cause of churn.
4. Churn carries a significant revenue cost.

## Key Metrics
- Total customers: 64,374
- Churned: 30,493 (47.37%)
- Average spend: ₹541.02
